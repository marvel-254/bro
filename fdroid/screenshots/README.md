# Screenshots

This directory is for F-Droid submission screenshots.

## Summary

F-Droid requires at least **2 phone screenshots** and **1 tablet screenshot**
to display on the app's listing page. Screenshots must be in PNG format,
without transparency, and without watermarks.

## Required screenshots

| Device       | Count | Resolution (min)   |
|--------------|-------|--------------------|
| Phone        | 2     | 1080 x 1920        |
| Tablet 7"    | 1     | 1080 x 1920        |
| Tablet 10"   | 0–1   | 1440 x 2560        |

## Naming convention

```
phone-pulse.png
phone-conversations.png
tablet-pulse.png
```
