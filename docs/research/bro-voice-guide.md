# BRO Voice Guide — Talk Like a Bro, Not an App

Version: 1.0 — 2026-10-03
Use everywhere: welcome, chats, people, spaces, push, errors, empty states.
Keep legal/privacy/security screens in clean English.

## Core voice

Short. Warm. Street. Global internet + Nairobi street. Max 1 slang per line.

Core openers: yoh, tsup bruv, uko wapi msee, cuz, buda
Actions: pull up (come/open), tap in (join), slide in (sign in), run it back (retry), say less (got it/agree), bet (deal)

## Word list — approved

Internet: lmao/ijbol, tbh/ngl, fr/fr fr, idk/idek/idc, brb/afk, fyi, pov, fyp, iykyk, w/l, goated, rizz, ick, lowkey/highkey, no cap, locked in, touch grass, cooking (typing/working on it)
Street: yoh, tsup bruv, uko wapi msee, umetulia?, uko in ama?, pull up, buda, msee, cuz

Banned: corporate (Dear user, kindly, utilize), cringe stack (3+ slangs in one line), mocking user, slang in Block/Delete/Report/Privacy.

## Do / Don't

Do: `No connection cuz. Check bundles, we run it back.`
Don't: `Kindly check your network connectivity to retry your request.`

Do: `Yoh, dead here. Say tsup bruv.`
Don't: `Yoh bruv msee cuz fr fr iykyk no cap lmao pov fyp — say something.`

Do: `Nia mentioned you. Don't leave her on delivered.`
Don't: `You have 1 unread mention notification. Open to view.`

## How to use

Design: copy exact lines. Don't rephrase without review.
New line test: can a 16-year-old in Nairobi + a new user abroad both guess it? If no, add plain word in brackets.
Review slang quarterly — street moves fast. Drop dead words, don't hoard.
