Install Guide

  1. Download the APK from the release above.
  2. Enable "Install unknown apps" for your browser/file manager in Android Settings.
  3. Install the APK. BRO runs on Android 7+.
  4. Join — create an account with Supabase inside the app.

No tracking, no ads, only INTERNET permission. Source code is GPL-3.0-or-later at github.com/marvel-254/bro.
