# BRO — TALK. CONNECT. EXIST.

BRO is a free and open-source social communication platform for Android. It is a living communication environment built around conversations, people, spaces, and presence.

## Features

- **Pulse** — Discover active people, live conversations, and recent activity
- **People** — Search, find, and connect with other users
- **Conversations** — Direct and group messaging with real-time sync
- **Conversation Branches** — Contextual threaded discussions off any message
- **Spaces** — Communities with members, conversations, and channels
- **Activity** — Replies, mentions, reactions, and invitations
- **Presence** — Real-time online status and typing indicators

## Installation

### From F-Droid

Search for **BRO** on F-Droid and install the latest release.

### From Source (Self-Build)

Prerequisites:
- Node.js 18+
- npm or yarn
- Android SDK (for building the APK)
- Java JDK 17+

Build instructions:

```bash
# Clone the repository
git clone https://github.com/marvel-254/bro.git
cd bro

# Install dependencies
npm install

# Type-check
npm run typecheck

# Lint
npm run lint

# Run tests
npm test

# Build for Android (via GitHub Actions)
# Push to a feature branch and the CI pipeline will build and upload the APK as an artifact.
```

### Building Locally

For local development builds only (not for distribution):

```bash
npx expo prebuild --platform android
cd android && ./gradlew assembleDebug && cd ..
```

> **Note**: The `android/` directory is generated by `expo prebuild` and is intentionally not committed. F-Droid builds the app using the source code and Gradle configuration generated at build time.

## F-Droid Build Notes

For F-Droid maintainers:

- **Build system**: Gradle (generated via `expo prebuild`)
- **Build command**: `cd android && ./gradlew assembleRelease`
- **Source code**: Fully open-source under GNU GPL v3.0+
- **Dependencies**: All dependencies are open-source (see `package.json`)
- **Third-party services**: Clerk (authentication), Convex (database/hosting) — see [PRIVACY.md](PRIVACY.md)
- **Required permissions**: INTERNET (for API and auth)
- **No tracking**: No analytics, crash reporting, or advertising SDKs
- **Reproducible build**: Yes (Gradle, no local signing config)
